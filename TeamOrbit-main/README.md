# TeamOrbit

Online Software Project Management Tool.

## Features

- User registration and login
- Admin, Manager and Team Member roles
- Team management
- Project management
- Task creation and assignment
- Task priority and deadlines
- Pending / In Progress / Completed workflow
- Automatic project progress calculation
- Overdue task detection
- Project Health dashboard
- Smart Task Assignment based on workload and task history

## Run

Open Command Prompt in this folder:

```text
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
